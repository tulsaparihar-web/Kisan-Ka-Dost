# Kisan Ka Dost – Android Starter

**Parihar Digital Labs**  
Hindi + English | Rajasthan-first | Offline-first

## Project details
- Package: `com.parihardigitallabs.kisankadost`
- Kotlin + Jetpack Compose + Material 3
- Navigation Compose
- Minimum Android: API 26 (Android 8.0)
- Compile/Target SDK: 35
- Java/JVM target: 17

## Open in Android Studio
1. Clone or download this repository.
2. Open the project root in Android Studio.
3. Set Gradle JDK to JDK 17 (Settings → Build, Execution, Deployment → Build Tools → Gradle).
4. Allow Gradle sync to complete. Android Studio may download Gradle and SDK components.
5. Run the app on an emulator or connected Android phone.

## Build APK
In Android Studio: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Expected debug APK:
`app/build/outputs/apk/debug/app-debug.apk`

## Included in Milestone 1 starter
- Home dashboard and feature navigation
- Hindi / English language switch, saved locally
- Farm Diary, Learn and Settings navigation placeholders
- Crop, plant, animal, tree, soil and scheme module placeholders
- No network permission or internet dependency

## Scope notes
This is starter source code, not a verified release build. Weather, AI, disease diagnosis, detailed agricultural content, Room database and farm records are reserved for later milestones. Screens marked as placeholders do not provide crop-disease diagnoses or veterinary treatment advice.
